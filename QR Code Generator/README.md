# QR Code Generator

A simple web-based tool to generate QR codes from text or URLs.

## Features
- Generate QR codes from text input
- Download QR codes as images
- Support for URLs, text, and contact information
- Real-time QR code generation
- Clean and minimal interface

## Technologies Used
- **HTML** - Input interface
- **CSS** - Minimal styling
- **JavaScript** - QR code generation (using external library)

## Files
- `index.html` - QR code generator interface
- `styles.css` - Styling
- `script.js` - Generation logic

## How to Use
1. Open `index.html` in your web browser
2. Enter text or URL in the input field
3. QR code will generate automatically
4. Download the QR code image if needed

## Installation
No installation required. Simply open the HTML file in any modern web browser.

## Dependencies
Uses a QR code generation library (included via CDN in the HTML file).
