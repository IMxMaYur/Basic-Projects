# Time & Date Display

An interactive time and date display application with various formatting options.

## Features
- Real-time clock display
- Current date display
- Multiple time formats
- Date formatting options
- Timezone support
- Responsive design

## Technologies Used
- **HTML** - Display structure
- **CSS** - Styling and layout
- **JavaScript** - Time and date logic

## Files
- `index.html` - Time and date interface
- `style.css` - Comprehensive styling
- `script.js` - Time/date functionality

## How to Use
1. Open `index.html` in your web browser
2. View the current time and date
3. Use format options to customize the display
4. The display updates in real-time

## Installation
No installation required. Simply open the HTML file in any modern web browser.

## Features
- 24-hour and 12-hour format options
- Various date formats
- Automatic time updates
