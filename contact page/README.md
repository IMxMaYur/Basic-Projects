# Contact Page

A professional contact form page with styling and backend integration.

## Features
- Professional contact form
- Form validation
- Email field validation
- Message input area
- Responsive design
- Thank you page after submission
- Backend email handling (PHP)

## Technologies Used
- **HTML** - Form structure
- **CSS** - Styling and layout
- **JavaScript** - Client-side validation
- **PHP** - Email handling backend

## Files
- `contact.html` - Main contact form
- `contact.css` - Form styling
- `contact.php` - Backend email handler
- `thankyou.html` - Confirmation page

## How to Use
1. Upload files to a web server with PHP support
2. Open `contact.html` in your web browser
3. Fill in the contact form with your information
4. Click submit
5. Upon success, you'll be redirected to thank you page

## Installation
1. Upload all files to your web server
2. Ensure PHP is enabled
3. Update the email recipient in `contact.php`
4. Test the form submission

## Form Fields
- Name (required)
- Email (required, must be valid)
- Phone (optional)
- Message (required)

## Note
Update the email address in `contact.php` to receive submissions.
