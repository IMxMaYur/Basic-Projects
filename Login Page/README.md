# Login Page

A professional login page with form validation and interactive features.

## Features
- Clean and intuitive login interface
- Form validation for email and password
- Password visibility toggle
- Responsive design
- Smooth animations and transitions

## Technologies Used
- **HTML** - Form structure
- **CSS** - Styling and responsive layout
- **JavaScript** - Form validation and interactivity

## Files
- `index.html` - Login form interface
- `style.css` - Page styling
- `script.js` - Form validation and functionality

## How to Use
1. Open `index.html` in your web browser
2. Enter your email and password
3. Click the login button
4. Form will validate your inputs and provide feedback

## Installation
No installation required. Simply open the HTML file in any modern web browser.

## Note
This is a frontend implementation. For actual authentication, integrate with a backend service.
