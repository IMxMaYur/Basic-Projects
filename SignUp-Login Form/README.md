# SignUp-Login Form

A comprehensive authentication form system with both signup and login interfaces.

## Features
- Professional signup form with validation
- Secure login form
- Form field validation
- Password confirmation
- Email validation
- Responsive design
- Smooth transitions between forms

## Technologies Used
- **HTML** - Form structure
- **CSS** - Responsive styling
- **JavaScript** - Form validation and interaction

## Files
- `signup-form.html` - User registration form
- `login-form.html` - User login form
- `signup.css` - Signup form styling
- `login.css` - Login form styling

## How to Use
1. Open `signup-form.html` for registration or `login-form.html` for login
2. Fill in the required fields
3. Form will validate your inputs
4. Submit when validation passes

## Installation
No installation required. Simply open the HTML file in any modern web browser.

## Validation Rules
- Email must be in valid format
- Password must meet security requirements
- Passwords must match in signup form
- All fields are required

## Note
This is a frontend implementation. For actual authentication, integrate with a backend service.
