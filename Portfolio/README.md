# Portfolio Website

A professional portfolio website showcasing projects, skills, and contact information.

## Features
- Multi-page portfolio structure (Home, Profile, Blog, Projects, Contact)
- Responsive design for all devices
- Professional styling and layout
- Contact form with email integration (PHP backend)
- 404 error page
- Image gallery support

## Technologies Used
- **HTML** - Page structure
- **CSS** - Responsive styling
- **JavaScript** - Interactivity
- **PHP** - Backend email handling

## Pages
- `Home.html` - Landing page
- `profile.html` - About/Profile section
- `blog.html` - Blog posts
- `project.html` - Project showcase
- `contact.html` - Contact form
- `404.html` - Error page
- `thankyou.html` - Thank you confirmation

## Files
- `.html` files - Page templates
- `.css` files - Styling for each page
- `.php` - Backend email handling
- `img/` - Image assets
- `script.js` - JavaScript functionality

## How to Use
1. Upload to a web server with PHP support
2. Update content in `.html` files
3. Customize `.css` files for branding
4. Configure `contact.php` for email handling
5. Open in web browser

## Installation
1. Download all files
2. Upload to web server
3. Ensure PHP support is enabled
4. Test contact form functionality
