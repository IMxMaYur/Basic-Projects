# Magic Square

An interactive magic square puzzle game with multiple implementations - JavaScript puzzle game and Python generator.

## Features
- Interactive magic square puzzle
- Drag-and-drop or click-based number placement
- Number arrangement validation
- Python generator to create magic squares
- Multiple difficulty levels

## Technologies Used
- **HTML** - Puzzle interface
- **CSS** - Styling and layout
- **JavaScript** - Game logic and interactivity
- **Python** - Magic square generation algorithm

## Files
- `index.html` - Main puzzle interface
- `puzzle.html` - Alternative puzzle view
- `puzzle.js`, `puzzle.css` - Puzzle game implementation
- `script.js`, `handle.js` - Game logic and event handling
- `generate_magic_square.py` - Python implementation for generating magic squares
- `styles.css` - Additional styling

## How to Play
1. Open `index.html` or `puzzle.html` in your web browser
2. Place numbers to form a magic square where all rows, columns, and diagonals sum to the same value
3. The game will validate your arrangement

## Installation
For the JavaScript version, no installation required.

For the Python version:
- Python 3.x required
- Run: `python generate_magic_square.py`
