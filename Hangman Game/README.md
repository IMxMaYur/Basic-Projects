# Hangman Game

A classic Hangman word-guessing game built with HTML, CSS, and JavaScript.

## Features
- Classic Hangman gameplay
- Random word selection
- Guess tracking (correct and incorrect guesses)
- Visual hangman drawing that progresses with wrong guesses
- Win/lose conditions

## Technologies Used
- **HTML** - Game structure
- **CSS** - Styling and visual feedback
- **JavaScript** - Game logic and interactivity

## Files
- `index.html` - Game interface
- `style.css` - Game styling
- `script.js` - Game logic

## How to Play
1. Open `index.html` in your web browser
2. Guess letters one at a time
3. Correct guesses reveal the letter in the word
4. Incorrect guesses add to the hangman drawing
5. Win by guessing the word before running out of attempts

## Installation
No installation required. Simply open the HTML file in any modern web browser.
