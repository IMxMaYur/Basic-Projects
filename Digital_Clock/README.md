# Digital Clock

A real-time digital clock displaying current time in a beautiful format.

## Features
- Real-time clock display
- Digital format (HH:MM:SS)
- Responsive and modern design
- Automatic time updates every second

## Technologies Used
- **HTML** - Clock structure
- **CSS** - Styling and animations
- **JavaScript** - Real-time clock functionality

## Files
- `digital-clock.html` - Main clock interface
- `clock.css` - Clock styling
- `clock.js` - Clock logic and time display

## How to Use
1. Open `digital-clock.html` in your web browser
2. The clock will automatically display the current time
3. The display updates in real-time

## Installation
No installation required. Simply open the HTML file in any modern web browser.
