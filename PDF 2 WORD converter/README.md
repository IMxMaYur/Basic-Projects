# PDF to WORD Converter

A Python utility to convert PDF documents to Word format (.docx).

## Features
- Convert PDF files to Microsoft Word format
- Batch processing capability
- Text extraction and formatting preservation
- Simple command-line interface

## Technologies Used
- **Python** - Core implementation
- **pdf2docx** or similar PDF parsing library

## Files
- `pdf2word.py` - Main converter script
- `exp 04.py` - Experimental/extended functionality
- `generate_magic_square.py` - Related utility
- Sample PDF and DOCX files for testing

## Requirements
- Python 3.x
- pdf2docx library: `pip install pdf2docx`

## How to Use
1. Install required dependencies: `pip install pdf2docx`
2. Run the converter: `python pdf2word.py`
3. Follow the prompts to select your PDF file
4. The DOCX file will be saved in the same directory

## Note
Conversion quality depends on PDF structure. Complex layouts may require manual adjustment.
