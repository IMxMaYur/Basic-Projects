# Tic-Tac-Toe Game

A classic Tic-Tac-Toe (Noughts and Crosses) game playable against another player or AI.

## Features
- Two-player gameplay
- Interactive game board
- Win detection
- Draw detection
- Restart game functionality
- Responsive design

## Technologies Used
- **HTML** - Game board structure
- **CSS** - Game styling
- **JavaScript** - Game logic and AI

## Files
- `index.html` - Game interface
- `style.css` - Game styling
- `script.js` - Game logic

## How to Play
1. Open `index.html` in your web browser
2. Players take turns clicking on empty squares
3. First player to get three in a row wins
4. The game detects wins and draws automatically
5. Click restart to play again

## Installation
No installation required. Simply open the HTML file in any modern web browser.

## Game Rules
- Players alternate between X and O
- First to get three in a row (horizontal, vertical, or diagonal) wins
- If the board fills without a winner, it's a draw
