# Weather Card

A weather information display card showing current weather conditions and forecasts.

## Features
- Current weather display
- Temperature, humidity, and wind speed
- Weather icons and conditions
- Location-based weather data
- Responsive card design
- Beautiful UI with weather imagery

## Technologies Used
- **HTML** - Card structure
- **CSS** - Styling and responsive layout
- **JavaScript** - Weather data handling
- **Weather API** - External weather data source

## Files
- `index.html` - Weather card interface
- `styles.css` - Card styling
- `images/` - Weather icons and background images

## How to Use
1. Open `index.html` in your web browser
2. Allow location access or enter a city name
3. View current weather conditions
4. The card displays temperature, humidity, and more

## Installation
No installation required. Simply open the HTML file in any modern web browser.

## Note
Weather data is fetched from a public API. Ensure an active internet connection for updates.
