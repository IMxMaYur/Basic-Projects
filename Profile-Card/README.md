# Profile Card

A stylish and interactive profile card component displaying user information.

## Features
- Professional profile card design
- User information display
- Profile picture integration
- Social links and contact information
- Smooth animations and hover effects
- Responsive design

## Technologies Used
- **HTML** - Card structure
- **CSS** - Modern styling and animations
- **JavaScript** - Interactive features

## Files
- `profile.html` - Profile card markup
- `profile.css` - Card styling
- `profile.js` - Interactive functionality
- `profile-pic 1.jpg` - Sample profile picture

## How to Use
1. Open `profile.html` in your web browser
2. View the profile card with all information
3. Interact with links and buttons as needed

## Customization
- Replace `profile-pic 1.jpg` with your own image
- Edit HTML to update user information
- Modify CSS for custom colors and styling

## Installation
No installation required. Simply open the HTML file in any modern web browser.
